Voice Commands

  • "Tell Status" / "Tank Status"
    AI replies if water is good or bad.
  • "Feed"
    Feeds the fish immediately.
  • "Pump on" / "Pump off"
    Toggles the water pump.
  • "Heater on" / "Heater off"
    Toggles the water heater.
  • "Fan on" / "Fan off"
    Toggles the cooling fan.
  • "Lights on" / "Lights off"
    Toggles the ARGB tank lights.
  • "Buzzer on" / "Buzzer off"
    Toggles the system buzzer manually.
  • "Auto Mode" / "Manual Mode"
    Changes the main operation mode.
