# SRAqua Guard Android

Android WebView wrapper for the supplied SRAqua Guard HTML dashboard.

- App name: SRAqua Guard
- Application ID: com.wrscn.sraquaguard
- Portrait orientation
- Internet permission enabled
- Immersive fullscreen
- Dark slate splash theme on Android 12+
- Original `index.html` and `assets/logo.png` bundled under `app/src/main/assets/`

## Build
Open this folder in Android Studio and let Gradle sync, then choose **Build > Build APK(s)**.

No Firebase credentials were added to the project; the supplied HTML keeps its existing setup flow.
